# tsumugi — 暮らしの収支管理

Python 3.12以降で動く、個人向け・ローカル専用の収支管理アプリです。追加ライブラリや外部フォント、インターネット接続は不要です。

## 起動

このフォルダで `python server.py` を実行して http://localhost:8000 を開きます。Windowsでは `start.bat` をダブルクリックして起動できます。終了はサーバーのウィンドウで Ctrl+C。

ポートを変更する場合: `python server.py --port 8001`
別のデータベースを使用する場合: `python server.py --db example.sqlite3`

## 機能

- ダッシュボード: 月間収支、収入、支出、収支率、過去6か月の推移、支出内訳、最近の記録
- 収支台帳: 月選択、内容・メモ検索、区分・カテゴリの絞り込み、日付・金額ソート、12件ごとのページ切り替え
- 記録の追加・編集・削除確認、メモ、日付と金額の入力チェック
- 月次レポート: カテゴリ別の前月比較と構成比
- CSV出力: 表示条件に一致する台帳、全期間、月次レポート。Excelで開きやすいUTF-8 BOM形式
- SQLiteの整合性を保ったバックアップ、ライト／ダーク、コンパクト表示、モバイルレイアウト

月間収支は当月の収入−支出です。繰越残高や銀行口座の残高ではありません。収支率は月間収支÷収入で、収入0円の場合は「—」になります。CSVの区分は収入／支出、金額は正の円単位です。式として解釈される可能性のある文字列には先頭にアポストロフィを追加します。

## データと復元

既存の `kakeibo.sqlite3` はそのまま引き継ぎます。初回のメモ欄追加前に `kakeibo.before-migration-日時.sqlite3` を自動保存します。空のデータベースにサンプル取引は追加しません。変更前のソースは `.backup` に保存しています。

設定・データ管理からデータベースをバックアップできます。復元する場合はサーバーを終了し、現在の `kakeibo.sqlite3` を別名で保管してから、バックアップを `kakeibo.sqlite3` としてこのフォルダに配置し、再起動してください。CSVの取り込みには対応していません。

本アプリは同じパソコン上での個人利用を対象としています。ログイン、複数ユーザー、クラウド同期、自動バックアップ、税務申告機能は実装していません。インターネット公開用のサーバーとして使用しないでください。バックアップには収支の全記録が含まれます。

## 検証

`python -m unittest test_server -v`
`node --check app.js`
`pnpm test:e2e`

APIテストは一時データベースを使い、既存データを変更しません。登録・更新・削除・永続化、不正入力、移行、バックアップの整合性、非公開ファイルの保護、別サイトからのアクセス拒否を確認します。

E2EテストはPlaywright Chromiumを使い、テスト専用の一時データベースとポートでサーバーを自動起動します。収支の登録・編集・検索・CSV出力・削除、ダッシュボードと月次レポートへの集計反映、表示設定の保存、モバイル表示を確認し、終了後に一時データベースを削除します。初回のみ `pnpm install` と `pnpm exec playwright install chromium` を実行してください。ブラウザを表示して確認する場合は `pnpm test:e2e:headed` を使用します。
